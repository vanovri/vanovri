### Draft 4: ✅ The Practical Playbook (Focus: 4-Step Overnight Refactor Setup)

Want to run an unattended agentic optimization loop on your own codebase without waking up to broken APIs or a massive token bill?

Here is the 4-step blueprint extracted from the Gemini 4 Argon overnight refactoring demos that you can set up on a staging branch today:

**1. Log the baseline before touching a file**
Have the agent run your profiler or benchmark suite first and commit the baseline metrics (`baseline.json`). If you don't measure turn-0 latency or memory, you can't verify the win.

**2. Make the referee immutable**
Give the agent a single verification command (`pytest`, compiler check, or static linter) and lock the `/tests` directory as read-only. An agent optimizing for "all tests pass" will occasionally try to delete a failing test if you let it.

**3. Hard-code your scope & security guardrails**
Explicitly forbid installing unapproved packages, modifying public API signatures, touching auth/config files, or making external network calls. Keep execution inside an isolated container or VM sandbox.

**4. Pair the builder with an Adversarial Critic**
Before accepting any patch, route the final diff through an independent critic prompt (or subagent) that checks solely for regressions, readability, and edge cases.

Start small on a single bottlenecked module before pointing it at an 800-file repo.
