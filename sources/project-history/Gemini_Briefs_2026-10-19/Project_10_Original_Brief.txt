Di demo ke-10 ini, Gemini 4 Argon mempertunjukkan kapabilitas penuhnya dalam merangkai ekosistem *real-time* multi-perangkat:

1. **Mobile Sensor Telemetry Stream:** Menggunakan API browser `DeviceOrientationEvent` (`beta` / tilt depan-belakang, `gamma` / kemiringan kiri-kanan) di handphone untuk mengubah HP menjadi raket tenis nirkabel.
2. **Low-Latency WebSocket Bridge:** Menjembatani sinyal kuaternion/Euler *swing* dari HP ke layar desktop via server WebSocket lokal.
3. **3D Three.js Court & Ball Physics:** Menghitung tumbukan bola tenis ($v_x, v_y, v_z$, koefisien restitusi, gravitasi, dan *spin*) saat memantul di lapangan rumput/tanah liat virtual.
4. **Live Audio Voice Commentary (Gemini TTS):** Setiap kali terjadi *ace*, *rally* panjang, atau *out*, event game dikirim ke **Gemini Flash TTS** untuk menghasilkan komentar suara olahraga (*play-by-play commentary*) secara instan.

### 1. WebSocket Bridge & Game Server (`argon_tennis_server.py`)

Script Python ini menjalankan server HTTP lokal dan WebSocket relay yang menerima data sensor giroskop dari HP dan menyiarkannya ke layar penampil 3D desktop:

```python
#!/usr/bin/env python3
import asyncio
import json
import logging
from typing import Set
import websockets

logging.basicConfig(level=logging.INFO)
connected_clients: Set[websockets.WebSocketServerProtocol] = set()


async def tennis_relay_handler(websocket, path):
  connected_clients.add(websocket)
  peer = websocket.remote_address
  logging.info(f"[CONNECT] Client connected from {peer}")
  try:
    async for message in websocket:
      data = json.loads(message)
      # Broadcast data giroskop handphone ke semua klien (layar desktop 3D)
      if connected_clients:
        await asyncio.gather(
            *[
                client.send(json.dumps(data))
                for client in connected_clients
                if client != websocket
            ]
        )
  except websockets.ConnectionClosedError:
    pass
  finally:
    connected_clients.remove(websocket)
    logging.info(f"[DISCONNECT] Client disconnected {peer}")


async def main():
  server = await websockets.serve(tennis_relay_handler, "0.0.0.0", 8765)
  logging.info(
      "[SERVER STARTED] Argon Tennis WebSocket Bridge running on ws://0.0.0.0:8765"
  )
  await server.wait_closed()


if __name__ == "__main__":
  try:
    asyncio.run(main())
  except KeyboardInterrupt:
    print("\n[SERVER STOPPED] Argon Tennis Bridge shut down gracefully.")

```
